# 项目 AGENTS.md 填写参考

这是未填写的示例，不参与安装。只把已核实且会影响决策的内容放进目标项目的 AGENTS.md；不保留占位符，不让 Agent 把未知内容补成事实。

```markdown
# 项目说明

## 入口与事实

实际代码入口、模块职责、状态存储位置，以及与直觉不同的项目行为。
只写理解任务需要的信息，详细说明链接到现有文档。

## 已确认约束

需要兼容的公开接口、明确的依赖方向、数据一致性或外部系统约束。
写明来源与适用范围。当前实现不自动等于不可变约束。

## 运行与验证

仓库实际可用的环境准备、运行和检查命令。
哪些测试需要外部服务，哪些命令可能修改真实数据。

## 本项目的取舍

例如当前版本的兼容目标、延迟目标或不支持的使用场景。
默认偏好与硬要求分别写，不堆通用工程口号。

## 凭据与外部影响

记录本项目实际采用的凭据来源和存储方式、选择它的环境前提与主要取舍，以及交付时真正会走的加载和验证入口。
开发、测试与生产如何区分；哪些请求会产生外部写入；模拟入口在哪里。
执行、部署、登录态读取和真实资金操作的授权范围。
未知的信息明确标为待确认，不推定环境隔离，也不把某种凭据存储机制本身当作验证已经完成。
```
