# 项目约定

## Usage

- 按项目语言和当前任务读取对应参考文件。
- 进入已有项目时，优先遵循项目现有工具链和约定。
- 新建项目、初始化项目或添加工具链时，使用对应的个人默认约定。
- 用户明确指定工具、框架或目录结构时，按用户指定来。
