# 交接结构

按下一会话的用途裁剪，没有内容的章节直接省略。

```markdown
# <任务交接>

## 目标与范围
当前要交付什么；下一会话是继续实现、复核还是调查。

## 接手入口
仓库或工作目录、分支与提交、相关未提交修改、spec／任务／产物路径。
记录时间，并标出对方尚无法访问的材料。

## 已完成与验证
做了什么，实际运行了哪些检查，证据在哪里。

## 未完成
待做工作、失败或未验证的部分、阻塞以及需要用户决定的问题。

## 决定与已排除的方向
引用已确认的决定；记录已经试过、确认行不通的方向。

## 下一步与授权
建议先做什么；已有授权到哪里，哪些外部动作仍需授权。
```
