# 交接参考结构

按下一执行者的用途裁剪，不重复已有产物。下面的字段是提示，不是要求每次生成全部章节。

```markdown
# <任务交接>

## 目标与范围
当前要交付什么；下一会话需要继续实现、复核还是调查。

## 接手入口
仓库／工作目录、分支与提交、相关未提交修改、Spec／任务／产物路径。
标明记录时的状态以及对方尚无法访问的材料。

## 已完成与验证
已经做了什么，实际运行过哪些检查，证据在哪里。

## 尚未完成
待做工作、失败或未验证部分、阻塞与真正需要决定的问题。

## 重要决定与排除项
引用已确认决定；只保留能防止重复走错方向的额外信息。

## 下一步与授权边界
建议先做什么；已有请求允许到哪里，哪些外部动作仍未授权。
```

记录环境和凭据名称而非值。暂存文件、未推送分支和私有链接不是天然共享入口；说明如何将必要材料交给下一会话，不能假定已经传递。
