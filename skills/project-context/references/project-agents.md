# 项目指令参考

用于创建或维护项目级 `AGENTS.md`，不是运行时全局规则。已有文件或其他宿主的指令文件优先增量维护，不为套模板另建一套；需要不同入口时避免两份全文独立漂移。

只留下后续 Agent 工作时需要直接知道的信息。下列结构可裁剪或并入已有章节；没有信息的章节直接省略，生成结果不保留占位文字。

```markdown
# 项目说明

## 工作入口

项目用途、相关模块入口，以及不明显的职责或依赖关系。
详细领域定义和设计背景引用已有文档，不复制全文。

## 运行与验证

实际可用的环境准备、运行和检查命令，以及适用的工作目录。
需要哪些外部服务，哪些检查已经运行；未运行的命令不写成验证通过。

## 已确认约束与取舍

需要保持的接口、数据语义、依赖边界或项目限制，并说明适用范围。
区分现状、已接受约束和默认偏好，重要理由引用对应决定记录。

## 环境与外部影响

凭据来源、配置键名和加载入口；只记录用法和路径，不记录秘密值。
说明相关环境前提、模拟或测试入口，以及哪些命令会产生真实外部写入。
记录已有授权边界，不因写入说明就扩大操作权限。
```

这个文件是工作入口，不是项目百科。不要复制用户级协作规则、通用工程教程或当前任务流水账。项目有更局部的指令范围时，就在对应范围记录，不把局部要求无条件提升为全项目规则。
